# Neural Network Lab Notes

Selected historical character-classification and sequence-model exercises.

## Source archive

`src/` contains selected model, training and plotting files. Data files, checkpoints, assignment PDFs and environment-test notebooks are excluded.

The selection includes small MLP exercises, character models and sequence-model training. It has not been retrained, and is not a complete dataset-independent demo. Dependencies are an unpinned starting list.


## Provenance

Originated in UNSW COMP9444. Source headers identify coursework scaffolding; ownership of provided framework code remains with its authors. Personal implementation changes must be distinguished before treating the notes as verified results.

## Verification status

Python syntax was checked. Model training and accuracy have not been reproduced; datasets and checkpoints are not bundled.
